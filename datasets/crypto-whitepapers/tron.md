## Summary

TRON is a smart-contract platform founded by Justin Sun. The TRON Foundation was set up in Singapore in July
2017, and TRX began as an ERC-20 token on Ethereum before moving to TRON's own mainnet in 2018. In July 2018
the foundation acquired BitTorrent.

The whitepaper describes a **delegated proof-of-stake** network in which TRX holders who stake their tokens
vote for 27 "Super Representatives", who take turns producing a block every 3 seconds. Smart contracts run
on the TRON Virtual Machine (TVM), which supports Solidity. The paper also defines TRON's token standards
(TRC-10 and TRC-20) and a resource model in which transactions consume "bandwidth" and "energy" that users
obtain by staking TRX.
