## Summary

The Ethereum whitepaper proposed a blockchain with a built-in Turing-complete programming language,
letting anyone write smart contracts and decentralized applications that define their own rules for
ownership, transaction formats, and state transitions. Where Bitcoin's scripting is intentionally limited,
Ethereum generalizes the blockchain into a global state machine: accounts hold code and storage, and
transactions trigger deterministic computation paid for in "gas." This made possible tokens, DAOs,
financial instruments, and applications far beyond payments. ethereum.org notes the 2014 paper predates the
live network and no longer reflects current Ethereum, but it remains the foundational vision document for
the entire smart-contract ecosystem.
