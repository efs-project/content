# Ethereum

- **Project:** Ethereum
- **Paper:** *Ethereum: A Next-Generation Smart Contract and Decentralized Application Platform*
- **Author:** Vitalik Buterin
- **Year:** 2014 (first circulated in late 2013)
- **Canonical source:** https://ethereum.org/en/whitepaper/
- **File in this folder:** `ethereum-whitepaper-2014.pdf` (the PDF edition published by ethereum.org;
  byte-identical to https://ethereum.org/content/whitepaper/whitepaper-pdf/Ethereum_Whitepaper_-_Buterin_2014.pdf)

## Summary

The Ethereum whitepaper proposes a blockchain with a built-in Turing-complete programming language, so that
anyone can write smart contracts and decentralized applications with their own rules for ownership,
transaction formats and state transitions. Where Bitcoin's scripting is deliberately limited, Ethereum turns
the blockchain into a general-purpose state machine: accounts hold code and storage, and transactions
trigger deterministic computation paid for in "gas". The paper sketches applications such as tokens,
financial contracts, decentralized autonomous organizations and name registries.

The network went live on 30 July 2015 using proof-of-work, and switched to proof-of-stake in "The Merge" on
15 September 2022. ethereum.org notes that the 2014 paper predates the live network and no longer
describes how Ethereum works today, but it remains the founding document of the smart-contract ecosystem.
