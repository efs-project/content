# Games

Fifteen small browser games, each a single self-contained HTML file published on EFS. Pick one and it plays right here: the explorer runs it in a sandboxed frame, so a game can run its own code but can't touch the page around it, your wallet, or anything else.

Every game's code and licence travel with it. Most are verbatim copies of their open-source originals; the few that were adapted to fit the frame say so on their file.

## Start here

- [Infernal Throne](https://app.efs.eth.limo/explorer/games/infernal-throne.html): a fast platformer from js13k 2022 (keyboard or gamepad).
- [Dante](https://app.efs.eth.limo/explorer/games/dante.html): a 3D exploration game, the js13k 2022 winner (keyboard and mouse, or touch).
- [Tiny Yurts](https://app.efs.eth.limo/explorer/games/tiny-yurts.html): a cosy road-building puzzle from js13k 2023 (mouse or touch).
- [Pong](https://app.efs.eth.limo/explorer/games/pong.html): play the computer, a friend, or watch a demo (keyboard, mouse or touch).

Then the classics: [Snake](https://app.efs.eth.limo/explorer/games/snake.html), [Tetris](https://app.efs.eth.limo/explorer/games/tetris.html), [Breakout](https://app.efs.eth.limo/explorer/games/breakout.html), [Sokoban](https://app.efs.eth.limo/explorer/games/sokoban.html), [Block Dude](https://app.efs.eth.limo/explorer/games/block-dude.html), [Helicopter](https://app.efs.eth.limo/explorer/games/helicopter.html), [Puzzle Bobble](https://app.efs.eth.limo/explorer/games/puzzle-bobble.html), [Doodle Jump](https://app.efs.eth.limo/explorer/games/doodle-jump.html), [Missile Command](https://app.efs.eth.limo/explorer/games/missile-command.html), [Frogger](https://app.efs.eth.limo/explorer/games/frogger.html) and [Bomberman](https://app.efs.eth.limo/explorer/games/bomberman.html). These are short, public-domain (CC0) teaching versions by Steven Lambert, each 4–13 KB of plain JavaScript you can read in one sitting.

Click a game once so it gets your keyboard.

## Why games?

A game is the clearest way to show that a file on EFS is more than a download link. Each one here is published once, under a permanent path, with its hash on-chain so anyone can check the bytes they received are the bytes that were published. Nobody, including whoever published it, can quietly swap in a different version.
