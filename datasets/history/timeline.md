# Ethereum Timeline

Key moments in Ethereum's history, from the whitepaper to today's upgrades. Each entry links to the
original document stored on EFS where there is one. Dates are UTC; block numbers and times come from
mainnet itself.

## 2013–2014: The idea

- **November 2013.** Vitalik Buterin writes the first draft of the Ethereum whitepaper in San Francisco.
  [Whitepaper](https://app.efs.eth.limo/explorer/whitepapers/ethereum-whitepaper-2014.pdf) ·
  [About the whitepaper](https://app.efs.eth.limo/explorer/whitepapers/ethereum.md)
- **23 January 2014.** "Ethereum: Now Going Public": Vitalik introduces the project, its team and the
  plan for an ether sale.
  [Read the post](https://app.efs.eth.limo/explorer/history/ethereum-now-going-public.md)
- **April 2014.** Gavin Wood publishes the Yellow Paper, a formal specification of the Ethereum protocol.
  [Yellow Paper](https://app.efs.eth.limo/explorer/whitepapers/yellowpaper.pdf) ·
  [About the Yellow Paper](https://app.efs.eth.limo/explorer/whitepapers/yellowpaper.md)
- **17 April 2014.** Gavin Wood's essay "ĐApps: What Web 3.0 Looks Like" sets out the vision of a
  decentralised web built on Ethereum.
  [Read the essay](https://app.efs.eth.limo/explorer/history/dapps-what-web3-looks-like.md)
- **22 July 2014.** The ether sale opens. It runs for 42 days, with ether bought in bitcoin.
- **24–28 November 2014.** Devcon 0, the first Ethereum developer conference, is held in Berlin.
  [Read the recap](https://app.efs.eth.limo/explorer/history/devcon-0-recap.md)

## 2015–2016: Launch and the DAO

- **30 July 2015.** Frontier, the first live release of Ethereum, launches. Block 1 is mined at
  15:26:28 UTC.
  [Ethereum Launches](https://app.efs.eth.limo/explorer/history/ethereum-launches.md) ·
  [The genesis block](https://app.efs.eth.limo/explorer/history/genesis-block.md)
- **7 August 2015.** Block 46,147 carries the first transaction, once miners have raised the gas limit
  above 21,000.
  [The genesis block](https://app.efs.eth.limo/explorer/history/genesis-block.md)
- **14 March 2016.** The Homestead upgrade activates at block 1,150,000.
- **17 June 2016.** An attacker begins draining ether from The DAO through a recursive-call bug.
  [CRITICAL UPDATE Re: DAO Vulnerability](https://app.efs.eth.limo/explorer/history/critical-update-re-dao-vulnerability.md)
- **20 July 2016.** The DAO hard fork activates at block 1,920,000. It moves the ether held by The
  DAO and its child DAOs, including the drained funds, into a contract from which DAO token holders can
  withdraw. The fork block's extra data reads `dao-hard-fork`.
  [EIP-779: Hardfork Meta: DAO Fork](https://app.efs.eth.limo/explorer/history/eip-779.md)

## 2020–2022: Proof-of-stake

- **1 December 2020.** The Beacon Chain, Ethereum's proof-of-stake consensus layer, launches alongside
  the proof-of-work chain.
- **5 August 2021.** The London upgrade activates at block 12,965,000, introducing EIP-1559's burned base
  fee.
  [EIP-1559](https://app.efs.eth.limo/explorer/standards/eip-1559.md)
- **24 August 2022.** The Ethereum Foundation announces the mainnet schedule for The Merge.
  [Mainnet Merge Announcement](https://app.efs.eth.limo/explorer/history/mainnet-merge-announcement.md)
- **6 September 2022.** The Bellatrix upgrade on the Beacon Chain prepares it for The Merge.
- **15 September 2022.** The Merge: block 15,537,393, mined at 06:42:42 UTC, is the last proof-of-work
  block, and Ethereum continues under proof-of-stake.
  [The last proof-of-work block](https://app.efs.eth.limo/explorer/history/last-proof-of-work-block.md) ·
  [EIP-3675: Upgrade consensus to Proof-of-Stake](https://app.efs.eth.limo/explorer/history/eip-3675.md)

## 2023–2025: Scaling and accounts

- **12 April 2023.** The Shanghai-Capella ("Shapella") upgrade activates at block 17,034,870, enabling
  withdrawals of staked ether.
- **13 March 2024.** The Cancun-Deneb ("Dencun") upgrade activates at block 19,426,587, adding blob
  transactions that make rollup data much cheaper.
  [EIP-4844: Shard Blob Transactions](https://app.efs.eth.limo/explorer/standards/eip-4844.md)
- **7 May 2025.** The Prague-Electra ("Pectra") upgrade activates at block 22,431,084. Among other
  changes, it lets ordinary accounts set code for themselves.
  [EIP-7702: Set Code for EOAs](https://app.efs.eth.limo/explorer/standards/eip-7702.md)
- **3 December 2025.** The Fulu-Osaka ("Fusaka") upgrade activates at block 23,935,694, introducing
  PeerDAS so nodes can check blob data by sampling it.
  [EIP-7594: PeerDAS](https://app.efs.eth.limo/explorer/standards/eip-7594.md)

For an overview of this folder, see
[Ethereum History](https://app.efs.eth.limo/explorer/history). Upgrade dates and block numbers match
ethereum.org's [history of Ethereum forks](https://ethereum.org/en/ethereum-forks/).
